# ashwath-04.github.io

Personal portfolio of Ashwath M, live at **https://ashwath-04.github.io**.

A single static page (HTML, CSS and a little JavaScript, no build step) with a sea-voyage theme: projects are
islands on a route map, experience is a ship's log, and the M.Tech thesis is the current voyage.

## Editing

| What | Where |
|---|---|
| About section | `index.html`, the paragraph under `<!-- ABOUT -->` |
| Certificate links | `index.html`, under `<!-- CERTIFICATES -->`: wrap each title in `<a href="...">` |
| Demo links | `index.html`, the `.links` line of each project card |
| Resume | replace `assets/docs/Ashwath_M_Resume.pdf` |
| Colours and fonts | the tokens at the top of `assets/css/style.css` |

Preview locally with `python -m http.server` in this folder, then open http://localhost:8000.
